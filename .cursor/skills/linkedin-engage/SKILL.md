# LinkedIn engage

## Before the next scheduled post

- Check P0 and the latest published post for unreplied comments. Draft replies in voice (`linkedin_ops/voice.md`).
- Daily 3 comments on others: healthcare AI, HIM, SLM/agents, speech. Each comment must add a measurement, a counterexample, or a precise question. Ban "great post" / "insightful".

## First 90 minutes after publish

1. Post the prepared first-comment sources immediately.
2. Reply to every comment. Practitioners first (HIM, healthtech CPTO, DS).
3. If asked for a model name or vendor bake-off, redirect to the **job** (schema, calibration, residency) not the stack.
4. Do not join engagement pods.

## After

Log notable commenters in `linkedin_ops/metrics.md` so research can target them.

Browser: user is usually already signed in. Prefer drafting replies here; only click LinkedIn if the user asked you to post the reply.
