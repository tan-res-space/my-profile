# LinkedIn draft

Read `linkedin_ops/voice.md` end to end. Read the target file under `linkedin_ops/posts/` and `calendar.yml`.

## Write

1. 120–220 words unless format is `document` (carousel).
2. First line must stand alone in the feed preview (before "...see more").
3. One measured claim max. Only numbers already in `voice.md` or supplied by the user this turn.
4. Exactly 3 hashtags from `linkedin_ops/hashtags.md`, last lines.
5. First comment: sources and the P0 permalink if this is a continuation. No links in the body.
6. Tag DeliverHealth only when the work is theirs.

## File

Update the post markdown: `status: drafted`, full body, first comment, first-hour notes. Set `calendar.yml` status to `drafted`.

## Show the user

Paste-ready body + first comment. State the slot (A or B) and the clock time in IST and ET. Ask them to schedule in LinkedIn native scheduler. Do not claim it was published.
