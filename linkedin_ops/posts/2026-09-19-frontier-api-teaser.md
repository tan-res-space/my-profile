# Body (paste into LinkedIn)

Do we need frontier APIs for automating tasks using agents?

Most stacks I see still say yes by default. Extract. Route. Fill a schema. Same giant model, every step.

That is convenient. It is also how an agent becomes a chat wrapper with a loop.

Frontier models are good at work you have not seen before. Most production tasks are work you have seen a thousand times.

For those jobs, the expensive API is a choice, not a requirement.

Wednesday: how you actually convert the stack. Not which 7B to download.
